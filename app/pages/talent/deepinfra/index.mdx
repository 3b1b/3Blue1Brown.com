## Featured work

### Cutting inference cost by up to 20x

We paired Mixture-of-Experts models with Blackwell-specific optimizations: NVFP4 quantization, speculative decoding, and memory management in TensorRT-LLM. A 405B dense model on H200 costs \$1.00 per million tokens; a 400B MoE model on B200 in NVFP4 costs \$0.05.

### Benchmarking NVIDIA's Vera CPU for agents

We benchmarked NVIDIA's Vera CPU against x86 chips on agentic workloads. Vera ran orchestration steps 2.2x faster than Sapphire Rapids and held 1.33–1.6x more sandboxed agents per core under a strict latency SLO. We also measured what microVM isolation actually costs.

### Serving frontier models on NVIDIA's inference stack

We serve frontier open models on B300 GPUs using TensorRT-LLM, NVIDIA Dynamo for distributed serving, and NVFP4 quantization. With this setup, one B300 does the work of four H200s on DeepSeek V4.
